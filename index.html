📐 How MAL Affinity Works

Affinity is the mathematical Pearson correlation coefficient ($r$) of scores on anime rated $> 0$ by both users. A score of +100% represents identical score changes, 0% is uncorrelated, and negative values indicate opposing taste.

Weighted Affinity applies empirical Bayesian smoothing ($k=15$) to prevent a user with only 2 shared anime from outranking someone with 85% affinity across 200 shared anime.

🌐 Running on GitHub Pages

Because MyAnimeList does not enable browser CORS headers, client-side requests from GitHub Pages require a CORS proxy.

You can deploy a 1-click free Cloudflare Worker (code included in /worker/) or run locally using python server.py for instant zero-config evaluation.
